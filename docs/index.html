Comparing Classification Algorithms on Breast Cancer Diagnostic Data

An evaluation of K-Nearest Neighbors, categorical Naïve Bayes, and a single-layer Perceptron using the Breast Cancer Wisconsin (Diagnostic) dataset.

Introduction

This study compares three supervised classification algorithms on a common, labeled diagnostic dataset.

How do different classifiers perform on the same diagnostic data?

The models predict benign (B) or malignant (M) labels from 30 numerical features. All three methods use the same held-out testing records.

This is a reproducible educational comparison. The trained models are not validated for clinical decision-making.

Dataset

The Breast Cancer Wisconsin (Diagnostic) dataset contains measurements computed from digitized images of breast mass cell nuclei.

569 observations
30 numerical features
2 diagnostic classes

Distribution of diagnosis labels

Benign (B): 357, 62.7% Malignant (M): 212, 37.3%

Original source: UCI Machine Learning Repository, Breast Cancer Wisconsin (Diagnostic).

Classification Methods

The methods use the same 30 predictor features and the same classification target, but differ in how they learn from training records.

01

K-Nearest Neighbors

Classifies a record using a majority vote among its five nearest training records.

k = 5; Euclidean distance; training-only Min-Max scaling

02

Categorical Naïve Bayes

Discretizes each numeric feature into three categories and estimates class-conditional probabilities.

Training-only 33rd and 67th percentile boundaries; Laplace smoothing, α = 1

03

Single-layer Perceptron

Learns a linear decision boundary by updating weights when a training example is misclassified.

Learning rate = 0.1; maximum 100 epochs; initial bias = 0.5

INTERACTIVE GUIDE

How does each classifier decide?

Select a model to explore the core idea behind its prediction process.

01 / NEIGHBORHOOD VOTING

Find the closest examples, then take a vote.

KNN compares a new record with the training records using Euclidean distance. In this project, the five closest records vote on the predicted class. The majority label becomes the prediction.

New record→5 nearest records→Majority vote→Class
02 / PROBABILITY

Estimate which class is most probable given the features.

Each numerical feature is discretized into one of three categories. Naïve Bayes combines the class prior and the feature likelihoods, treating features as conditionally independent. Laplace smoothing helps avoid zero probabilities.

Feature categories→Class probabilities→Compare scores→Class
03 / LINEAR DECISION

Learn weights that separate the two classes.

The Perceptron calculates a weighted sum of the input features and applies a decision rule. When a training example is misclassified, it updates its weights and bias to improve later predictions.

Input features→Weighted sum→Decision rule→Class

Experimental Setup

All models were evaluated against the same held-out testing set. Scaling and discretization boundaries were derived only from training data.

427 training records
142 testing records
Training: 427 records (75%) Testing: 142 records (25%)

The 569 observations were separated using a stratified 75/25 train-test split. A fixed random seed (67) was used when preparing the split to support reproducibility. Malignant (M) is the positive class; evaluation reports accuracy, malignant recall, and confusion matrices.

Discussion

K-Nearest Neighbors achieved the highest test accuracy, while KNN and Perceptron obtained equal malignant recall on this split.

Interpretation

KNN correctly classified 140 of the 142 test records. Perceptron correctly classified 139, while categorical Naïve Bayes correctly classified 134. Results reflect this particular data split and configuration.

Limitations

Categorical discretization reduces numerical precision. The Perceptron did not converge within 100 epochs. No clinical validation, external cohort testing, or diagnostic deployment is claimed.

Conclusion

The models produced different results under a common evaluation procedure. On this test split, KNN performed best in overall accuracy.

These findings illustrate differences between methods, not evidence that any model is suitable for medical diagnosis.
